# Code of Conduct

This project follows the spirit of the [Contributor Covenant 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).

**Our standard.** Be respectful and constructive. Assume good faith. Critique code and ideas, not people. Harassment, discrimination, personal attacks, and publishing other people's private information are not acceptable.

**Scope.** This applies in issues, pull requests, discussions and any other space where someone represents the project.

**Enforcement.** Maintainers may edit, hide or remove contributions that violate this standard, and may restrict participation. To report a problem, open a private security advisory on the repository or contact the maintainer through their GitHub profile.
