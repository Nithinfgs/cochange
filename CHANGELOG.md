# Changelog

## 0.1.0

First release.

- `cochange check`: finds companion files missing from working-tree, staged or branch changes.
- `cochange of <file>`: shows what usually changes with a file.
- `cochange backtest [--sweep]`: leave-one-out replay on a repo's own history.
- `cochange report`: self-contained HTML coupling map.
- `cochange hook <claude|pre-commit|github>`: integration snippets; Claude Code Stop hook mode.
- Output formats: text, JSON, Markdown, GitHub annotations.
- Rename following, bulk-commit filtering, lift filtering and recency weighting.
